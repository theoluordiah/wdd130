Develop the Home page
Based on the Rafting Site Project Description, develop the main home page for the site according to the following requirements:

The home page is named index.html and is located in the wwr rafting website project directory.
This file is different than the week 1 index.html page which was your personal home page for the course and is located in a different location. The name index is a default file name which is referenced by the web server to be delivered to the requesting client for any directory in which it resides.

The one (1) common CSS file is used throughout the site, rafting.css.
One large full-width hero image is used and it includes a heading message that is positioned on the hero image using CSS position: absolute.
A newsletter sign up form that requests at least a name and an email.
A call to action with link to the trips.html page that compels visitors to visit the trips page.
A CSS grid layout with at least two additional images and corresponding content about the white water rafting site purpose and offerings.
The layout of the page cannot be a simple, single-column flow layout for full credit consideration.
Be creative in your design, but remember that your header, navigation, and footer layout and content must be the same as other pages on the rafting site to support good design and user experience on the site as a whole.
Develop the Trips page

Then, develop the page according to these requirements:

At least three detailed trip descriptions with photos.

For full credit consideration, you cannot just have a simple, single-column flow layout.
